Save profile.yaml and contract.yaml into a directory,
      then run the three commands on the Run it tab. The model checker enumerates the
      authority space your profile declares and tells you whether any configuration lets a
      resource move without a valid approval. It takes about a hundredth of a second and needs no
      network, no model weights, and no GPU.

    

      
Do not copy another domain's assurance claims. The reference results
        describe the reference profile. A new domain inherits the structure and none of the
        evidence; borrowing results is how a method decays into a vocabulary.
