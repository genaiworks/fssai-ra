# Security policy

The project is a teaching reference and is not production-certified. Security
corrections are applied to the latest tagged release and the `main` branch.

Do not disclose an unpatched vulnerability, secret, or personal record in a public
issue. Use GitHub's private vulnerability reporting for this repository when it is
available. If that channel is unavailable, contact the maintainer through the GitHub
profile without including exploit details in a public message.

Read the complete [threat model](fssai-ra/docs/SECURITY.md) and
[assurance matrix](fssai-ra/docs/ASSURANCE.md) before evaluating or deploying the code.
